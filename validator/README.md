From the repository root, install NumPy with `python3 -m pip install -r validator/requirements-dev.txt` in your Python environment. Run `python3 -m unittest discover -s validator/tests` without building Kotlin. Run `./gradlew clean build` with JDK 25 to exercise the installed CLI and generate audio and measurements under build/validator/. To inspect one fixture, run `python3 validator/check_audio.py build/validator/ae-t-257.wav`.

The reference assumes no leading or trailing gap. The first and last threshold crossings must lie within 6 ms of the file edges. We locate marks above 10% of peak amplitude and bridge interruptions shorter than 3 ms around carrier zero crossings. A 5 ms raised-cosine ramp crosses 10% about 1 ms from its edge. Waiting for a 600 Hz crest can add up to another half cycle per edge. The 6 ms segment allowance covers both edges and one sample of quantization. Pitch uses interpolated rising zero crossings over each whole mark. The ±2 Hz allowance exceeds the effect of a one-sample endpoint error over a 60 ms dot. These measurement settings target the 600 Hz acceptance fixtures.
