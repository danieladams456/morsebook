# morsebook
The best Morse code listening experience

## Core
CW synthesizer optimized for pleasant, low-fatigue listening.  Think Elecraft sidetone.

## CLI
Render audio files for human and programmatic spectrum analysis.  This allows us to iterate on the sound outside the end-user app.

## App
Provide the user experience of top-tier audiobook apps with the advantage of a ridiculously compressed text-based library (and Morse code practice.)
