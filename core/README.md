ASCII letters are case insensitive. Digits use International Morse. Whitespace runs separate words, with no initial or terminal silence. Punctuation and unsupported characters are ignored. Marks last one or three units. Gaps within characters, between characters and between words last one, three and seven units respectively. Each unit is 1.2 / WPM seconds. Fractional samples carry forward between segments. Each mark has a raised-cosine attack and release of up to 5 ms.
